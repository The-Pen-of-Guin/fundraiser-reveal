# Scene API

An API is defined for setting of scene configurations. A scene
surrounds how the animation will look. For instance, the scene
defines the background color, text color, and font.

## Set Background Color

Sets the color of the background.

`POST /api/v1/scene/background/color`

## Set Font

Sets the font to use in the scene.

`POST /api/v1/scene/text/font`

## Set Text Color

Sets the text color.

`POST /api/v1/scene/text/color`
